# References and video lessons

These external sources explain standard methods. The repository's assignment wording, scenarios and figures were newly written; linked content is not republished.

## Open teaching references

- Åström and Murray, *Feedback Systems*: [open textbook and supplements](https://fbsbook.org/) and [Caltech lecture index](https://www.cds.caltech.edu/~murray/FBS/Lecture_Index.html) — feedback, stability, state estimation and robustness.
- [APMonitor Dynamics and Control](https://apmonitor.com/pdc/) — modeling, simulation and controller design.
- [APMonitor PI control](https://apmonitor.com/pdc/index.php/Main/ProportionalIntegralControl) — PI conventions, windup and the IMC-style rule used in the capstone.
- [APMonitor second-order systems](https://apmonitor.com/pdc/index.php/Main/SecondOrderSystems) — transient-response methods.
- [Python Control 0.10.2 documentation](https://python-control.readthedocs.io/en/0.10.2/) — models, feedback, margins and simulation.
- [Pole placement API](https://python-control.readthedocs.io/en/0.10.2/generated/control.place.html) — gain convention and repeated-pole restrictions.
- [SciPy least_squares](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html) — bounded nonlinear least squares.
- [GNU Octave control package](https://gnu-octave.github.io/packages/control/) — portable control-system calculations.
- [MathWorks programmatic model construction](https://www.mathworks.com/help/simulink/ug/approach-modeling-programmatically.html) — Simulink generation APIs.

## Physical-modeling case studies

- [APMonitor tank blending](https://apmonitor.com/pdc/index.php/Main/TankBlending): species and energy balances, with an [embedded energy-balance lesson](https://www.youtube.com/watch?v=8-V5T40aMEc).
- [APMonitor liquid-level control](https://apmonitor.com/pdc/index.php/Main/LevelControl): gravity-drained tank control, with an [embedded Python control lesson](https://www.youtube.com/watch?v=FMs00ovzpoI).

These are further-study references. The interacting-tank topology, numerical parameters, questions and artwork in this repository were authored independently; the APMonitor cascade example uses a different connection arrangement.
