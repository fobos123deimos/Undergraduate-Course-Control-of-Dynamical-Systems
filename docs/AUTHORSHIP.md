# Authorship and scope

This edition was newly written for the repository. It uses original hypothetical scenarios, assignment wording, a new exercise sequence, new diagrams and independently implemented programs. Broad course topics informed coverage; no original handout, translated worksheet, copied figure, document scan or source-file manifest is distributed.

Changing names or numbers in an existing worksheet would not meet this edition's purpose. The learning objectives and situations were redesigned: sensor lag versus physical temperature, airflow linearization error, floor-motion transmissibility, notch tolerance, motor disturbance paths, delay budgets, sampling stability and held-out synthetic identification.

Balance laws, Routh-Hurwitz, standard compensator formulas, PID, pole placement, observers, zero-order hold and established tuning rules are not claimed as original scientific inventions. Their references are listed separately. The course-context Lattes acknowledgment appears only in the root README and does not imply authorship or endorsement of this new material.

No blanket claim is made over referenced external books, videos, software or websites. The repository contains its own teaching artifacts and links to those external resources.
